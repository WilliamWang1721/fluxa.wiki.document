# 汇丰中国 大湾区企业账户通

汇丰中国商业理财「大湾区企业账户通」官方说明页。

| 字段 | 值 |
| --- | --- |
| URL | https://www.business.hsbc.com.cn/zh-cn/campaigns/gba/account-connect |
| 类型 | official |
| 发布方 | 汇丰中国 |
| 可信等级 | primary（官方现页） |

该页写明可通过指定内地分行做视频会谈及见证签字，协助开立汇丰香港企业账户；客户可通过指定内地分行完成汇丰香港视频会谈开户和汇丰中国账户开户见证。备注称：账户开户是否成功取决于公司能否完全满足汇丰香港的开户要求，以及在现行外汇管理法规框架下是否允许在香港开户。部分服务需获得内地、港、澳三地监管部门批准后方可开展。
