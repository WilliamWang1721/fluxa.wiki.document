# HSBC HK 汇丰儿童储蓄账户

[[banks:hsbc-hong-kong|HSBC HK]](../banks/hsbc-hong-kong.md) 官方 **汇丰儿童储蓄账户** 产品页（与 HSBC CN 的 **汇丰卓越理财青少年成长账户** 为不同子行、不同产品）。

| 字段 | 值 |
| --- | --- |
| URL | https://www.hsbc.com.hk/zh-cn/accounts/products/savings/children/ |
| 类型 | official |
| 发布方 | HSBC HK |
| 可信等级 | primary（官方现页） |

要点（以官方页为准）：

- 面向 **18 岁以下**儿童；无手续费或最低结余要求（页面表述）。
- **11 岁以下**：可由父母/监护人以**父母名义**为子女开立；父母须**陪同**子女到分行完成开户。
- **11 岁及以上**：儿童可申请属于自己的账户；开户仍须父母或监护人陪同到分行。
- 满 18 岁可升级至 HSBC One 等成人账户（页面「做好准备升级成人理财」）。
