# 中银香港 见证开户服务

中银香港官网「見證開戶服務」产品页。

| 字段 | 值 |
| --- | --- |
| URL | https://www.bochk.com/m/tc/crossborder/personal/financialservicehk/account.html |
| 类型 | official |
| 发布方 | 中银香港 |
| 可信等级 | primary（官方现页） |

该页称申请人毋须亲临香港，亦可于内地、澳门或香港以外的指定见证网点签署中银香港开户文件，开立「中銀理財」「智盈理財」账户，并申请网上银行及电话银行。开户途径之一是透过指定境外见证网点办理见证及提交申请。指定网点名单以该页链接为准，本词条不转抄。
