# 汇丰中国大湾区人民币 II 类结算账户服务协议

汇丰中国官方服务协议，仅适用于通过汇丰香港代理见证开立的人民币 II 类结算账户。

| 字段 | 值 |
| --- | --- |
| URL | https://www.hsbc.com.cn/content/dam/hsbc/cn/docs/document-download/gba-cny-type-ii-settlement-account-service-agreement-cn.pdf |
| 类型 | terms |
| 发布方 | 汇丰中国 |
| 可信等级 | primary（官方现页） |

协议把香港上海汇丰银行有限公司称为见证银行，把汇丰银行（中国）有限公司称为开户银行：见证银行负责面见、初步核实身份并传送开户资料；开户银行负责审核开户资料、办理开户并承担账户全生命周期管理。所有大湾区 II 类账户均由汇丰中国开立、维持并提供相应账户服务。用途、限额与销户规则以协议现行文本为准。
